# يوميات مواطن عراقي 3D — صعد الدولار!

لعبة متصفح كوميدية عربية ثلاثية الأبعاد، Babylon.js + TypeScript + Vite. هذا إصدار أول قابل للعب بعالم سوق صغير؛ ليس نموذج الوجه الواقعي الموجود في المرجع ولا يعادل جودة صورة العرض المسبقة.

## تشغيل

Node.js 20.19+ أو 22.12+:

```sh
npm install
npm run dev
npm run check
npm test
npm run build
```

## اللعب

جولة مدتها 90 ثانية. توجه إلى حامل لافتة «صعد الدولار!» واقترب منه وواجهه ثم نفّذ الضربة الكرتونية. التفاعل الناجح يعطي **100 نقطة فقط**، مع عداد Combo منفصل؛ لا تضاعف النقاط. أول شخصية تظهر بعد بدء الجولة، وبعدها كل 10–20 ثانية، وبحد أقصى شخصيتين نشطتين. تصاعد النقاط يقصر الفترة تدريجياً ضمن هذا النطاق. لا دماء أو إصابات واقعية.

- الحاسبة: WASD للحركة، Shift للركض، Space للقفز، E للضربة، F للتفاعل. اسحب بالماوس لتدوير الكاميرا.
- الهاتف: عصا يسار، أزرار يمين، واسحب على المشهد لتدوير الكاميرا. العصا وأزرار الحركة تدعم مؤشرات لمس مستقلة.
- توقف تلقائي عند فقدان التركيز. زر نكمل لاستئناف الجولة.
- أعلى نتيجة والجودة والصوت محفوظة محلياً، مع معالجة بيانات تالفة وزر إعادة ضبط.

## ما هو موجود فعلاً

ساحة سوق عراقية صغيرة مترابطة: أرصفة ومحلات بلافتات عربية، مظلات، صناديق خضار، سيارات صفراء، نخيل وأعلام وعمارة خلفية. شخصية اللاعب بهودي أبيض وجينز، وشخصية مسؤول كرتوني ببدلة وشارب ودبوس العلم. الشخصيات **أصول إجرائية أصلية مفصلية**؛ الحركة مصنوعة برمجياً وليست موشن كابتشر. كاميرا متابعة مع فحص العوائق، تصادم حركة، قفز، ضربة بشرط المسافة والاتجاه، ظهور/سقوط/اختفاء، جزيئات واهتزاز، شاشة نتائج ومشاركة واتساب وخريطة خفيفة.

الصوت الكوميدي مولد عبر Web Audio؛ الإعلان العربي يستعمل SpeechSynthesis حسب الأصوات العربية المتاحة في جهاز الزائر. لا يوجد تسجيل صوتي عراقي بشري مرفق. لا تحتاج اللعبة مفاتيح API أو حسابات أو أصول خارجية أثناء اللعب.

## إضافة GLB وصور مرجعية

تدعم اللعبة نماذج GLB/GLTF عبر Babylon SceneLoader. النموذج الأول `official-original.glb` نموذج كرتوني أصلي صُدِّر من rig إجرائي، مع حركات Idle / Walk / HitReaction / Fall. هو نموذج مبسط غير مطابق للوجه المرجعي. يمكن إعادة توليده بـ `npm run assets`، ويوجد rig إجرائي احتياطي عند تعذر تحميل GLB. وضع ملف GLB في تعريف الشخصية يستبدل جسمها تلقائياً مع الإبقاء على اللافتة ومنطق الجولة. عند فشل التحميل يبقى النموذج الإجرائي وتظهر رسالة في Console.

1. ضع نموذجاً مرخصاً في `public/models/characters/` وخاماته المدمجة داخله، أو ملفات GLTF المرافقة في المجلد نفسه.
2. ضع الصورة المرخصة في `public/textures/` إن احتجتها؛ لا يعرض المحرك الصورة باعتبارها وجهاً ثلاثي الأبعاد.
3. أضف تعريفاً إلى `public/characters.json`:

```json
{
  "id": "official-02",
  "name": "شخصية جديدة",
  "model": "./models/characters/official-02.glb",
  "reference": "./textures/reference.webp",
  "scale": 1,
  "rotationY": 0,
  "animations": { "idle": "Idle", "walk": "Walk", "hit": "HitReaction", "fall": "Fall" }
}
```

الارتفاع المناسب للجسم نحو 2.4 وحدة، نقطة الأصل عند القدمين، والاتجاه الأمامي +Z. إن كان النموذج أمامه -Z استخدم rotationY = 3.14159265. يفضل أقل من 15 ألف مثلث، خامات 512/1024، وGLB أقل من 3MB. النموذج المخصص يمكنه تشغيل حركات Idle وHitReaction وFall حسب أسماء التعريف. مسار Walk مجهز للتوسع؛ الشخصيات الحالية ثابتة بعد الظهور ولا تتجول.

افتح `/admin.html` لمختبر محلي: استعراض صورة وGLB، رؤية أسماء الحركات، وتصدير JSON. الملفات تبقى في ذاكرة الصفحة فقط؛ **لا تُرفع ولا تحفظ عاماً ولا تنتج نموذج وجه تلقائياً**. لابد من إضافتها للمستودع وإعادة البناء. يحتاج رفع حقيقي لاحقاً Backend وتخزيناً وصلاحيات.

## Cloudflare Pages

اربط هذا المستودع ثم اختر الفرع المراد نشره (حالياً `codex/playable-3d`، أو `main` بعد دمج طلب التغيير).

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Environment: `NODE_VERSION=22`

المسارات نسبية لدعم النشر في مجلد فرعي. لا يوجد Backend. ملف manifest يدعم الفتح كتطبيق مستقل؛ على iPhone استخدم Safari ثم مشاركة ← إضافة إلى الشاشة الرئيسية. **لا يوجد Service Worker أو دعم offline كامل** في هذا الإصدار. أيقونات PNG بحجمي 192/512 وapple-touch-icon مرفقة.

## الأداء

الجودة Low تلغي الظلال وتخفض دقة الرسم، Medium ظلال أخف، High دقة أوضح. أجزاء النخيل المتكررة تستعمل instancing، الخريطة تُحدّث عدة مرات في الثانية بدلاً من كل إطار، والحد شخصيتان مع جزيئات قصيرة العمر. تتوقف حلقة الرسم بالخلفية. الشخصية والعالم يستخدمان خامات بسيطة بلا ملفات صور ثقيلة.

30/60fps **أهداف لم تُقَس على هاتف حقيقي**. يلزم قياس على iPhone Safari وAndroid Chrome قبل إعلان اعتماد الإصدار. تحسين إضافي مطلوب: دمج هندسة الواجهات، تقليل أجزاء rig وتحميل نماذج مضغوطة عند توفرها.

## الاختبارات والتحقق

`npm test` يتحقق من: ظهور آمن بعيداً عن العوائق، مسافة واتجاه الضربة، احتساب 100 مرة واحدة، Combo، نهاية الجولة، إعادة الجولة، وحدود فترة الظهور. `npm run check` للتحقق من TypeScript و`npm run build` لإنتاج dist.

يتحقق اختبار NullEngine من تهيئة المدينة والخامات والتصادمات وحركات rig ودورة NPC وتحميل GLB وحركاته الأربع بدون نافذة متصفح.

اختبار متصفح فعلي، وضوح العربية في Canvas، مسارات GLB، الحركة والكاميرا، اللمس المتعدد، تبديل الاتجاه، الصوت وفقدان التركيز على iOS/Android، **تحتاج اختباراً بصرياً على المتصفح والأجهزة**. لا تعتبر نجاح build اختبار تشغيل للمشهد.

## حدود النسخة وما يحتاج عملاً إضافياً

- لا يوجد وجه مطابق للصورة. يلزم فنان 3D ونموذج GLB مرخص بملامح وحركات مخصصة للاقتراب من المرجع.
- المدينة والشخصيات مصممة إجرائياً بأسلوب مبسط؛ صورة المرجع أعلى كثافة وتفصيلاً بكثير.
- سقوط NPC حركة برمجية مبالغ بها، وليس محاكاة ragdoll فيزيائية.
- الانتقال بين المشي والركض برمجي؛ الضربة والقفز لا يستخدمان Skeleton Animation للاعب.
- يلزم صوت عراقي مسجل مرخص، أصول وجه وملابس أكثر تفصيلاً، وفحص أداء أجهزة فعلية.
- لا تنشر أصولاً لا تملك حق استخدامها. الصورتان المرجعيتان لا يتم نسخهما إلى المشروع أو إعادة توزيعهما.

## هيكل

`src/core`, `world`, `player`, `npc`, `gameplay`, `controls`, `ui`, `data`, `utils`; أصول المشروع داخل `public/models`, `textures`, `audio`, `icons`. مجلدات الأصول الفارغة تحتوي توثيقاً استعداداً للإضافات. كل الكود والأشكال الأصلية لهذا الإصدار أُنشئت لهذا المشروع؛ Babylon.js مرخص Apache-2.0، Vite وTypeScript وtsx وفق تراخيص حزمها.
