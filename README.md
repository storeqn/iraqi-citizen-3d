# المواطن ضد الغلاء 3D

**الراتب ثابت والأسعار تطير!** لعبة كوميدية عربية RTL على Babylon.js + TypeScript + Vite/WebGL. إعادة بناء للعبة السابقة في المستودع نفسه، مع الإبقاء على أصولها ووحداتها غير المستخدمة لضمان عدم ضياع العمل القديم. الفرع الجديد: `codex/citizen-vs-inflation`؛ الفرع السابق `codex/playable-3d` لم يتغير.

## التشغيل

Node.js 22:

```sh
npm install
npm run dev
npm test
npm run check
npm run build
```

`npm run assets` يعيد توليد نموذج المواطن الأصلي GLB بحركات Idle / Walk / Run / Jump / Interact / Celebrate / Sad. الأصول والرسم البرمجي أصلية. لا تُستخدم الصور المرجعية كخلفية أو كوجه ملصق على مجسم، ولا يوجد نموذج وجه مستخرج من صورة شخص حقيقي.

## المراحل المنفذة

| المرحلة | طريقة اللعب | هدف الفوز |
|---|---|---|
| السوق الشعبي | حركة حرة بين خمس بسطات، E للتفاعل والشراء، ارتفاع افتراضي للأسعار كل 22 ثانية | شراء تمن وخبز وبيض وخضرة وچاي ضمن 35 ألف وقبل 120 ثانية |
| مطاردة الدولار | ركض تلقائي، تحريك يمين ويسار، قفز، دنانير وفواتير في مسارات | بلوغ 160 متراً وجمع 8 دنانير قبل الإصابة الثالثة |
| الفواتير | الوصول لدائرة الخدمات، ثم اختيار ترتيب السداد | أربع فواتير واحتياط 80 ألف؛ تأخير الإيجار بعد عمليتين يغير النتيجة |
| الراتب الشهري | الوصول للمصرف، استلام مليون دينار، ثلاث موجات سعر افتراضية، سؤال تفاعلي | إدراك الفرق بين الراتب الاسمي والقدرة الشرائية |
| المواصلات | الوصول للموقف، الاختيار بين التفاوض والتكسي والباص والمشي | الوصول خلال 30 دقيقة افتراضية والاحتفاظ بـ8 آلاف |
| مفاصلة الأسعار | الحوار مع البائع، آخر سعر وعرض كمية وقبول أو أسلوب فظ | شراء بأدب بـ26 ألف أو أقل |
| بيت المواطن | الدخول إلى غرفة معيشة مفتوحة، أخبار وقرارات ميزانية | تغطية الضروريات الأربع مع احتياط 100 ألف |
| تحديات الحياة | ثلاث ألعاب قرارات متتابعة: وقود، هاتف، مدرسة | 10 لترات بالضبط، هاتف ≤300 ألف، مدرسة واحتياط 100 ألف |

المرحلتان الأولى والثانية تعتمدـان على الحركة والتصادم داخل المشهد ثلاثي الأبعاد. المراحل 3–8 تتطلب الوصول لموقع التفاعل في المدينة ثم تعرض قرارات وحوارات HTML فوق العالم. هي تحديات ميزانية فعلية بربح وخسارة، وليست محاكاة قيادة تكسي أو حركات واقعية لتعبئة الوقود. الوقت يتوقف أثناء نافذة القرارات لتسهيل القراءة على الهاتف. جميع المراحل متاحة مستقلة، وزر التالي يربطها بمسار متتابع.

الأسعار والراتب والفواتير وموجات الغلاء **افتراضية للعبة فقط**. لا تمثل أسعار سوق أو سعر صرف حالي. احتساب القدرة الشرائية: الراتب الاسمي ÷ مؤشر السعر النسبي؛ عند المؤشر 1.25 يصبح مليون دينار بقوة شرائية مكافئة لـ800 ألف بأسعار البداية. ليس سعر صرف الدولار هو مؤشر الأسعار نفسه، ولا تدعي اللعبة علاقة واحد لواحد بينهما.

## العالم والشخصية

سوق صغير مترابط مع بسطات خضار ومواد غذائية، لافتات محلات عربية، سيارات صفراء، نخيل وأعلام، أرصفة وشوارع، نقاط مصرف وخدمات وموقف، وغرفة معيشة قابلة للدخول بأريكة وتلفزيون وطاولة. الدولار شخصية نقدية خيالية أصلية بلا تشابه مع شخص حقيقي. شاشة البداية تعرض المواطن والدولار متحركين في المشهد نفسه، وليست صورة مرجعية ثابتة.

نموذج المواطن GLB أصلي مفصلي: هودي، جينز، شعر وشارب ووجه مبسط. الحركة Transform Animation Groups وليست تحريكاً متقدماً بهيكل عظمي أو موشن كابتشر. النموذج البديل البرمجي يبقى متاحاً إن فشل تحميل GLB. الرسومات كرتونية بسيطة ومتناسقة؛ **لا نعتبرها مطابقة لجودة الصورة المرجعية أو لعبة تجارية عالية التفاصيل**. إضافة نماذج احترافية وخامات ووجوه أكثر تعبيراً تحتاج عمل فنان 3D. ملفات اللعبة لا تحتوي صور أشخاص حقيقيين.

## التحكم

- حاسبة: WASD، Shift للركض، Space للقفز، E للتفاعل، Escape للاستراحة، اسحب الماوس لتدوير الكاميرا.
- هاتف: عصا الحركة، قفز وتفاعل، وسحب المشهد للكاميرا. مؤشرات لمس منفصلة للعصا والسحب والأزرار وSafe Areas للآيفون.
- في المطاردة: ركض تلقائي، العصا/WASD لتغيير المسار؛ الكاميرا ثابتة خلف اللاعب. المسار يدور ضمن المدينة الصغيرة ويعيد استعمالها؛ ليس عالماً مفتوحاً لا نهائياً.
- عند فقدان التركيز تتوقف المرحلة وتُحفظ. استأنف يدوياً. نافذة إعدادات متاحة من الاستراحة.

## الاقتصاد والحفظ

`src/economy/wallet.ts`: دفتر مصروفات ومعرفات فريدة، يمنع الرصيد السالب وتكرار صرف/إيداع العملية نفسها. `src/missions/session.ts`: حالات المراحل والتحقق من الانتصار. `src/minigames/runner.ts`: مواقع الدنانير والفواتير وشروط الاصطدام.

مفتاح الحفظ `citizen-inflation-v2` مستقل عن بيانات اللعبة السابقة. حفظ تلقائي أثناء اللعب وعند الاستراحة، مع استئناف القرارات والمشتريات والمسافة والدنانير التي جُمعت. الموضع المكاني في مراحل الحركة الحرة يعاد إلى نقطة الدخول عند الاستئناف؛ لا تُعاد مشترياتك. إجمالي النقاط مجموع أفضل نتيجة لكل مرحلة؛ إعادة اللعب لا تكرر مكافآت النجاحات. إنجازات ونتائج محلية فقط، بلا حسابات أو Backend أو ترتيب عالمي. لون الهودي محفوظ محلياً.

التحقق من الحفظ يتعامل مع JSON تالف، إعدادات غير صالحة ومعرفات مكررة، ويطابق الرصيد مع الميزانية ودفتر المصروفات. زر إعادة الضبط يطلب تأكيداً داخل الواجهة ويمسح تقدم هذه النسخة فقط.

## الرسومات والأداء والصوت

Low / Medium / High تضبط الدقة والظلال وكثافة التفاصيل. سقف Render Resolution عند High هو 1.75× CSS بكسل، Medium 1.2×، وLow 0.8×. Instancing للنخيل، LOD هندسي لمنتجات البسطات، إخفاء تفاصيل بعيدة، ظلال 512/1024، وتحديث خريطة خفيف. يتوقف الرسم في الخلفية. GLB والمحمل يُحملان تدريجياً، وشاشة التحميل تعكس اكتمال تجهيز البيئة ثم بايتات النموذج إن أعلن الخادم حجمها، ثم جاهزية المشهد والخامات؛ ليست عداداً زمنياً وهمياً.

30fps على هاتف متوسط و60fps عند الإمكان أهداف **غير مقاسة على أجهزة فعلية**. بعض حزم المحرك أكبر من 500KB قبل الضغط. الأصوات توليدية عبر Web Audio (نقود، خطوات، مركبة، قفز ونتائج) مع تعبير اختياري بصوت عربي من الجهاز عبر SpeechSynthesis. لا توجد أصوات عراقية بشرية مسجلة أو ملفات أصوات أشخاص.

## Cloudflare Pages

- Repository: storeqn/iraqi-citizen-3d
- Production branch: `codex/citizen-vs-inflation`، أو الفرع المستهدف بعد دمج طلب التغيير
- Framework preset: Vite أو None
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: فارغ
- Environment variable: `NODE_VERSION=22`

**إن كانت الاستضافة الحالية على `codex/playable-3d` فستظل تعرض اللعبة السابقة حتى تبديل Production branch إلى الفرع الجديد أو دمج التغييرات إليه.** لم تُعدّل إعدادات حساب Cloudflare من هذه المهمة.

المسارات نسبية، والـmanifest والأيقونات تدعم الإضافة للشاشة الرئيسية. لا يوجد Service Worker لتجنب فرض كاش تطبيق قديم؛ لا يوجد offline كامل. على iPhone: Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية. `/admin.html` مختبر GLB وصور محلي موروث؛ لا يرفع الأصول للاستضافة، وتخصيص المظهر داخل اللعبة من الإعدادات.

## التحقق

انظر QA.md للنتائج المنفذة والحدود. اختبارات منطق لكل مرحلة، دفتر المصروفات، المكافآت والاستئناف، ثم تهيئة مشهد عبر NullEngine وتحميل GLB. النجاح فيها لا يعادل اختبار WebGL بصري أو اختبار Safari/Android فعلي. لا ينبغي ضمان غياب أي مشكلة GPU أو إعلان تطابق الصورة المرجعية قبل الاختبار البصري.

## المتبقي للتحسين

نماذج وشخصيات احترافية أكثر تعبيراً، انتقالات Animation blending أدق، أصول مصرف وخدمات داخلية أوسع، محاكاة حركة للمراحل القائمة على القرارات إن رغبت، تسجيلات عراقية مرخصة، واختبارات لمس وكاميرا وأداء على أجهزة فعلية. صور بطاقات المراحل رسومات SVG أصلية، وليست لقطات شاشة تدعي جودة المشهد.
